Tạo HELLO (code trên): điền node_id, địa chỉ quảng bá, chain_id, height đã chốt; ký bằng Domain.HELLO rồi encode thành Message canonical giống mọi message khác.

Kiểm HELLO (code dưới) theo thứ tự, lỗi đầu tiên gặp là reason:

4. Framing: vì sao cần 4 byte độ dài

TCP là một dòng bytes liền, không giữ ranh giới message. Bên gửi đặt 4 byte độ dài trước mỗi message; bên nhận đọc đủ 4 byte, rồi đọc đúng chừng ấy byte.

vàng = header 4 bytexanh / tím = nội dung
Bên gửi: frame(m1) + frame(m2)
Bên nhận nhận theo từng mảnh (│ đỏ = chỗ TCP cắt)
read_frame() ghép lại:

Frame lớn hơn MAX_FRAME (= giới hạn message của encoding.py) bị từ chối ở cả hai đầu: bên gửi log send_too_large, bên nhận đóng kết nối với reason frame_too_large.

7. Mô phỏng gossip trên 10 node full mesh

Bấm một node để nó phát message, rồi "Bước tiếp" để xem từng hop. Tăng mất gói rồi tắt "Chuyển tiếp": không chuyển tiếp thì cạnh bị drop là node đó mất message luôn; có chuyển tiếp thì message đi đường vòng. Đổi lại, chuyển tiếp tạo nhiều bản trùng và dedup (mục 5, bước 13) bỏ hết. Test tương ứng: test_forwarding_routes_around_dropped_link.
